Honest product scope

Explore the product as it exists today.

QuotePilot is a local-first application prototype. Quote records stay in this browser. AI, email, payment processing and cloud persistence are mocked and do not send real messages or collect payments.

Frequently asked

Know what you’re trying.

Can I try this without an account?

Yes. Open the interactive demo. No signup is required for this prototype.

Is this a production SaaS?

No. It is a pre-launch prototype. Review the stated scope and missing production integrations before relying on it for business-critical work.

Does it connect to external services?

Only features explicitly implemented in the current app work. The scope notice above explains what is simulated or not connected.

Where can I review the implementation?

The public repository contains the source and product notes. The demo is intended for evaluation, not as a promise of production readiness.
