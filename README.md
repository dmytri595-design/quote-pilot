# QuotePilot v0.4.0 — multi-page product demo

QuotePilot is a static product prototype for contractor/service-business estimating.

## Pages
- Dashboard
- New Quote
- Quotes
- Customers
- Analytics
- Settings
- Quote Detail

## v0.4 additions
- Versioned product shell (v0.4.0)
- Quote workflow stepper
- AI extraction / confidence panel
- Detected scope, labor, materials and assumptions
- Quote detail view
- Local browser state hooks for future persistence
- Explicit production roadmap for AI, pricing, email and payments

The AI layer is simulated in this demo. No external API credentials are stored in the repository.
